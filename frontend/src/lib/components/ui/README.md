# shadcn-svelte components

Generated by `shadcn-svelte` from the `rhea` style (see `../../../../components.json`). Prettier
skips this directory (`.prettierignore`) so a diff after an update shows only upstream changes.

## Customising

Prefer, in order: classes at the call site (`cn()` merges them over the base), CSS variables in
`src/app.css`, a wrapper in `src/lib/components/`. Edit a file here only when none of those can reach
it, and mark the edit so it survives the next overwrite:

```svelte
<!-- LOCAL: why this differs from upstream. Reapply after `add -o`. -->
```

`grep -rn "LOCAL:" src/lib/components/ui` lists every edit to reconcile.

## Updating

```bash
git status --porcelain src/lib/components/ui ui.lock.json   # must be empty
bun run ui:drift                                            # which components changed upstream
bunx shadcn-svelte@latest add -o <component>...             # overwrite (there is no `diff` command)
git diff src/lib/components/ui                              # the review
bun run check && bun run build
bun run ui:drift -- --record                                # accept the new baseline
```

Update a few components at a time, and bump `bits-ui` in the same commit. Changing `style`,
`baseColor` or `iconLibrary` in `components.json` changes every file: use `shadcn-svelte init
--reinstall`, then `add -o` for each installed component.
